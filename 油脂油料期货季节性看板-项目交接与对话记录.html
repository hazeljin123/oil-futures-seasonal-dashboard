六、如何恢复 / 继续改

改任何图或规则，只改 build_dashboard.py 后重跑：

cd 项目目录 && python3 build_dashboard.py

（用托管 Python：/Users/hazeljin/.workbuddy/binaries/python/versions/3.13.12/bin/python3，需先建 venv 装依赖——本脚本仅用标准库，可直接跑）

重跑会重新抓取新浪数据 + 生成 油脂油料期货季节性看板.html（同时复制到 ~/Desktop）。全部历史「如何恢复」见 .workbuddy/memory/2026-09-12.md。

七、数据源与限制

  • 数据源：新浪期货日线接口（免费）。你最初给的 HTFC_API_KEY=undefined / HTFC_BASE_URL=https://ent.htfc.com 都是占位符，未启用，也未从那个地址装任何技能（安全红线）。
  • 历史回溯：新浪仅保留到 2018/2019 年（2017 及更早返回空），故展示的 2019–2027 即全部可调历史，无法更早。
  • 若以后要更长历史或实时性更强：接付费源（有效 HTFC / Wind / Tushare 凭证），把 build_dashboard.py 的抓取段换掉即可。

九、为什么是打包而不是 GitHub

原计划把项目推到 GitHub 以便另一台 clone，但本机命令行无 GitHub 凭证（网页登录不算），且尝试时 GitHub 被墙无法访问。遂改为：把整个项目（含本交接文档）打成 zip，明天用 U 盘 / AirDrop / 网盘 拷到另一台解压即可。
